# Scripts

Helper utilities that are not part of the core evolution loop.

| Script | Purpose |
|--------|---------|
| `validate_run_outputs.py` | Checks on a finished `data/outputs/<run>/` directory |
| `run_mpi_tests.sh` | MPI test suite under `mpiexec` |
| `_run_with_timeout.py` | Timeout wrapper used by `run_mpi_tests.sh` |

Research drivers live under `experiments/evostar_2027/`.
